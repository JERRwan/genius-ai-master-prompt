# BRIENNE AI — MASTER DEVELOPMENT PROMPT

You are a world-class AI software architect, Python engineer, AI engineer, UI/UX designer, automation engineer, and cybersecurity-focused systems developer.

Build a complete, working desktop AI assistant called **BRIENNE AI**.

BRIENNE AI should be inspired by the intelligence, voice interaction, futuristic interface, automation abilities, and local computing style of J.A.R.V.I.S. from the Iron Man movies, but it must be an original real-world implementation and must not copy copyrighted movie assets, dialogue, branding, or source code.

## 1. MAIN GOAL

Create a highly advanced AI desktop assistant that can:

1. 🤖 Control applications, files, and approved computer tasks.
2. 🛠️ Help design, code, research, and create technology projects.
3. 🛡️ Analyze potential threats, system problems, and security risks for defensive purposes.
4. 📡 Control authorized local systems, applications, and connected devices.
5. 🎙️ Hold natural voice and text conversations.
6. 🧠 Process local data and provide intelligent recommendations.
7. 🔌 Work offline without requiring a cloud AI API key.

The primary local AI engine must use **Ollama**.

BRIENNE AI must remain useful even when the computer has no internet connection, provided Ollama and a downloaded local model are available.

# 2. REQUIRED TECHNOLOGY STACK

Use:

* Python 3.11 or later
* PyQt6 for the desktop interface
* Ollama for offline LLM inference
* SQLite for local memory and settings
* Requests or httpx for Ollama API communication
* SpeechRecognition or equivalent for speech input
* pyttsx3 for offline text-to-speech
* sounddevice / PyAudio where appropriate
* PyAutoGUI for approved GUI automation
* psutil for process and system monitoring
* pathlib and os for file operations
* subprocess for controlled application launching
* python-dotenv for environment configuration
* Rich for terminal logs
* Pydantic for command schemas and validation

Avoid requiring a paid API key.

Optional online features may use APIs only when the user explicitly enables them.

# 4. OFFLINE AI BRAIN

BRIENNE AI must communicate with Ollama through:

http://127.0.0.1:11434

Automatically detect whether Ollama is running.

Before generating a response:

1. Check whether Ollama is available.
2. Detect installed models.
3. Allow the user to choose a model.
4. Send conversation history efficiently.
5. Stream responses where possible.
6. Detect and display errors clearly.
7. Never silently fail.

Recommended local models should include options suitable for low-end and medium computers.

The system must work with any compatible model installed through Ollama.
