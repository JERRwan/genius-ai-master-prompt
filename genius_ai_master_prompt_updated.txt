47. INSTALLABLE APP EXPERIENCE
==================================================

The React/Vite version must also work as an installable Progressive Web App (PWA), while remaining fully usable as a normal website in supported modern browsers. Users must be able to install GENIUS AI as an app on Windows, macOS, Linux, Android, and iOS wherever the browser supports installation.

PWA FOUNDATION

Implement the following:

- Provide a valid web app manifest with the name GENIUS AI, short name, description, start URL, standalone display mode, theme color, background color, and suitable 192x192 and 512x512 application icons.
- Register a versioned service worker for the app shell, static assets, and an offline fallback page.
- Do not cache private conversations, uploaded documents, audio, images, or other sensitive user data unless the user explicitly enables local storage.
- Support secure HTTPS deployment in production and localhost development for testing.
- Make the installed experience responsive, accessible, fast, and visually consistent with the browser version.

USER-FRIENDLY INSTALL PROMPT

When a user has started using GENIUS AI and the browser reports that installation is available, show a polite, non-blocking custom prompt such as:

"Install GENIUS AI on your device for faster access and an app-like experience."

The prompt must:

1. Appear only after meaningful use or a short delay, not immediately on the first page load.
2. Detect whether GENIUS AI is already installed or running in standalone mode and avoid showing the prompt in that case.
3. Use the browser's supported installation event when available rather than displaying a misleading prompt.
4. Include clear actions such as INSTALL NOW, NOT NOW, and DISMISS.
5. Respect the user's choice, avoid repeatedly interrupting the user, and store dismissal state locally without storing private conversation content.
6. Close automatically after installation or dismissal.
7. Be keyboard accessible, screen-reader friendly, mobile responsive, and easy to understand.
8. Never block chat, study, research, document, or other core functionality if the user declines installation.

PLATFORM-SPECIFIC GUIDANCE

- On supported Chromium-based desktop browsers, provide an in-app install button or banner when the browser exposes an install event. Also document the browser menu installation option.
- On supported Android browsers, provide the same install flow and explain that GENIUS AI may be added to the home screen.
- On iPhone and iPad browsers where an automatic installation event is unavailable, show optional instructions such as OPEN SHARE MENU → ADD TO HOME SCREEN. Do not pretend that an automatic prompt is available when it is not.
- If installation is unavailable, do not show a broken button. Instead, hide the prompt or show a brief explanation in Help or Settings.

STREAMLIT VERSION

The Streamlit version should remain fully usable in a browser. Where automatic PWA installation is not available, provide a non-intrusive Help or Settings card explaining how the user can use the browser's Install or Add to Home Screen option when supported. Do not claim that every Streamlit deployment can be installed as a native desktop application.

TESTING AND DOCUMENTATION

Test and document:

- First-time display of the install prompt after meaningful use.
- Correct behavior when the app is already installed.
- Installation acceptance and dismissal.
- Reopening the app in standalone mode.
- Desktop, Android, and iOS guidance.
- Offline app-shell loading and graceful offline messaging.
- Protection of private conversations and uploaded files from unintended service-worker caching.
- Exact README steps for installing and uninstalling GENIUS AI as an app.

Include the manifest, service worker, icons, install prompt component, browser detection logic, offline fallback, automated tests where practical, and README documentation in the final project.
